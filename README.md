# CodeAlpha Internship Tasks

This repository contains the Python projects completed as part of my CodeAlpha Internship.

## Tasks

### Task 1 – Hangman Game
A simple command-line Hangman game developed using Python.

**Features:**
- Random word selection
- User can guess letters
- Displays correct and incorrect guesses
- Limited number of attempts
- Shows the final result

**File:** `hangman.py`

---

### Task 2 – Stock Portfolio Tracker
A simple Python program to calculate the total value of a stock portfolio.

**Features:**
- Predefined stock prices
- Enter stock names
- Enter quantity of stocks
- Calculates the value of each stock
- Calculates the total portfolio value
- Displays the portfolio summary

**File:** `stock_portfolio.py`
